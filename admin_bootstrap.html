🎒 조·방 데이터 주입 도구

학생 명단 엑셀 업로드 후, 이 페이지의 버튼을 눌러 조·방 배정 데이터를 admin의 임시저장에 주입하세요.

📋 사용 순서

  1. admin.html을 먼저 열어 로그인하고 [가져오기] 탭에서 엑셀 업로드 → 덮어쓰기로 커밋 (학생 303명이 들어가야 함)
  2. 반드시 같은 브라우저·같은 도메인에서 이 페이지를 열기 (그래야 localStorage 공유됨)
  3. 아래 [주입 실행] 버튼 클릭
  4. admin.html 탭으로 돌아가 [🔄 임시저장에서 불러오기] 클릭 → [조 편성], [방 배정] 탭에서 결과 확인
  5. 확인 후 [Firebase 동기화] 탭 → [☁️ 전체 한번에 업로드]

⚙️ 주입 실행

현재 admin의 localStorage에 저장된 학생 데이터에 조·방 정보를 추가합니다. 학생 데이터는 삭제/변경되지 않아요.

  


  

    
📦 포함된 데이터

    

      조 편성: 71개 조 (서울 자유여행, 5/7)

      방 배정: 82개 방 (더트리니 호텔, 7~25층)

      학생 매핑: 303명 전원 (조·방 정보 연결)
