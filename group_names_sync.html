🏷️ 조 이름 Firebase 주입 도구

학생 앱에 하드코딩된 조 이름 69개를 Firebase groups/{n}.name에 한 번에 주입합니다.

📋 사용 순서

  1. 같은 도메인에서 admin.html에 최소 한 번 접속해서 학생·조 데이터가 올라가 있는지 확인
  2. 아래 [Firebase 현재 상태 불러오기]로 현재 조 데이터 조회 — 변경 예정 사항 미리보기 표 확인
  3. 문제없으면 [조 이름 주입 실행] — name 필드만 업데이트하며 다른 필드(leader, theme, course_list 등)는 그대로 유지
  4. 완료 후 teacher.html에서 조 이름이 제대로 보이는지 확인
